# Сайт-портфолио Ксении Берёзиной

Готовый статический сайт без сборщика и платных сервисов. Подходит для GitHub Pages. Адаптирован под телефон и компьютер.

## Как открыть локально

Откройте файл `index.html` в браузере. Интернет нужен только для загрузки шрифтов Google Fonts: без него сайт также работает на запасных системных шрифтах.

## Как заменить демонстрационные работы на свои

1. Скопируйте фотографии макетов в папку `assets/`. Желательно JPG/WebP, размер около 1200–1600 пикселей по ширине.
2. Откройте файл `content.js` в любом текстовом редакторе.
3. В разделе `works` у нужной работы замените `image: ''` на `image: 'assets/имя-файла.jpg'`.
4. Обновите `title` и `description` на реальные название и описание работы. Для новых карточек добавьте новый объект по примеру существующих.
5. В разделе `videos` вставьте настоящую ссылку в `url: ''` и при желании путь к обложке в `poster: ''`.
6. Цифры в блоке «Результаты» добавляйте **только по подтверждённой статистике**. Сейчас там стоят прочерки и пояснения.
7. Вместо блока с монограммой в разделе «Обо мне» можно вставить фотографию: в `index.html` замените содержимое `<div class="about-visual">...</div>` на `<div class="about-visual"><img src="assets/portrait.jpg" alt="Ксения Берёзина" style="width:100%;height:100%;object-fit:cover"></div>`.

Визуальные заглушки намеренно помечены как места под реальные материалы. Это не готовые примеры ваших работ.

## Как опубликовать на GitHub Pages

1. Зарегистрируйтесь на [github.com](https://github.com).
2. Создайте новый **публичный** репозиторий, например `portfolio`.
3. Загрузите **содержимое** этой папки (файлы `index.html`, `styles.css`, `script.js`, `content.js`, `README.md`, `.nojekyll`, папку `assets`) в корень репозитория. Не кладите всё внутрь ещё одной папки.
4. В репозитории выберите **Settings → Pages**.
5. В **Build and deployment** выберите **Deploy from a branch**; branch `main`, folder `/ (root)`; нажмите Save.
6. После публикации адрес будет `https://ВАШ_ЛОГИН.github.io/portfolio/`.

## Изменения и обновления

Достаточно изменить файлы в репозитории: GitHub Pages автоматически обновит сайт. Для изменения цветов и типографики редактируйте `styles.css`, для текстов основных разделов — `index.html`, для карточек галереи и видео — `content.js`.

## Важно перед отправкой работодателям

- Добавьте минимум 4–6 реальных работ и 2–3 ссылки на видео.
- Проверьте сроки работы, контакты, названия проектов и права на публикацию рабочих материалов.
- Впишите реальные цифры статистики, если можете их подтвердить.
- Встроенный блок «Запросить PDF-резюме» сейчас открывает письмо. Чтобы дать скачать PDF, положите актуальный файл в `assets/resume.pdf` и замените ссылку кнопки в HTML на `href="assets/resume.pdf"` с атрибутом `download`.
- Не выкладывайте материалы клиентов, если условия работы запрещают публикацию.

Сайт: HTML + CSS + JavaScript. Нет аналитических скриптов, cookies, формы сбора данных или отправки данных на сторонние сервисы.
